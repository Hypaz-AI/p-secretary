Cosa fa

Un agente, tre modi di lavorare
 

Dialogo

Chiedilo in linguaggio naturale.
Esempio: «quante fatture ho ricevuto a settembre?»
 

Posta in arrivo

Riassume ogni messaggio.
Crea attività solo con citazione esatta.
Ti disturba solo per le emergenze.
 

Riepilogo serale

Recap delle ultime 24 ore.
Piano delle successive 48.
Principi

Il modello non è mai l'autorità

Il server decide cosa è permesso. Il modello propone, non esegue.

Agisce solo con il tuo OK

Calendario ed email diventano proposte: le confermi con /conferma o /invia.

Consensi default-deny

Permessi negati di default, per canale.
Revocarne uno nasconde subito i dati.

Tuoi dati, tua infrastruttura

Docker multi-piattaforma (amd64 e arm64, anche Raspberry Pi 4). Dashboard sulla rete locale.

Come iniziare

Tre passaggi
01

Clona il repository

git clone https://github.com/Hypaz-AI/p-secretary.git
02

Configura le variabili

Chiavi, account e consensi partono da .env.example. Guida completa in docs/CONFIGURATION.md.
03

Avvia

Con il launcher ./p-secretary up. La dashboard risponde sulla rete locale.
